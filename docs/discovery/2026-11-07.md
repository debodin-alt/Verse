## Implemented but still unverified

- Actual human microphone capture, acceptable volume/headphone routing/latency, mix quality, drift and clipping on iPhone/wireless routes and supported browsers.
- Phone lock/app switch/call/disconnect stop-save behaviour; crash/force-quit and pre-first-chunk loss; decoding partial recovered media on real target browsers.
- Large-library/long-take resource pressure, blocked upgrades, full corruption/oversize import atomicity, other old-version fixture variations and device-native transfer.
- Full mobile/accessibility compliance, VoiceOver, software keyboard, focus/contrast/target sizes. Earlier 390px layout observation is only partial evidence. Lighthouse unavailable in this session.
- Hosted-byte parity, production security headers, independent operational backups and source-to-deployment recovery.

## Missing for the agreed direction

Offline startup; independent voice/backing stems; safe concurrent writes; complete release automation; automatic off-device backup/cross-device sync; commercial identity/access/billing/support and store builds. Existing recordings are mixed assets, not hidden recoverable voice stems.

## Product, security and maintenance implications

Keep the current experience. A rewrite would not cure these audio/data issues by itself. Establish storage correctness and native/browser device proof first, then choose any native capability required. No new framework, backend, service, payment or data migration has been introduced.

Security/privacy review remains limited: validated/escaped boundaries exist, but there is no comprehensive hostile-import test set, secrets-history scan or production-header audit. Browser/backup data are not application-encrypted; optional dictation needs provider/privacy clarity. Private hosting does not encrypt browser storage. The public source repo is not itself a publication of local creative content.

Low maintenance favours managed services and a small surface, not a zero-maintenance promise. The draft commercial plan proposes independent backup/sync and a costed audio allowance before selling; neither a provider nor recurring spend is approved.
