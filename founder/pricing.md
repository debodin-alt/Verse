## Costs to resolve before committing

- Web domestic-card Stripe processing currently lists **1.65% + A$0.30**; Stripe Billing pay-as-you-go lists **0.7% of Billing volume**. International/currency/refund/tax/store costs differ. These components are not an all-in cost or a margin calculation. [Stripe Australia](https://stripe.com/au/pricing).
- Managed infrastructure can have a meaningful fixed floor: Supabase's public page lists Pro from **$25/month**, while free projects can pause after inactivity. No plan selected and displayed-dollar currency must be confirmed before budgeting in AUD. [Supabase pricing](https://supabase.com/pricing).
- Object storage alone is not an app backend: Cloudflare R2 lists standard storage at **$0.015/GB-month**, plus operation pricing and applicable allowances; identity, database, backups and application work are separate. No storage provider selected. [R2 pricing](https://developers.cloudflare.com/r2/pricing/).
- App-store fees/policies, account programmes, media bandwidth, backup retention, support/refunds and incident work must be included in a commercial scenario. Do not promise zero maintenance or zero running cost from a free tier.

Before a public paid release: measure a representative audio library and capture duration; select a managed service and cost ceiling; model annual gross price, applicable tax, purchase channel fees and storage/support costs; then run `/founder-cfo` with explicit sources and scenarios. Survey real buyers' four price-sensitivity questions before running `/founder-pricing`'s range tool. An accountant should check tax treatment before money moves.
